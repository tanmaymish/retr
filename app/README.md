# Akshayvridhi

A React + Vite implementation of the "Safebox.life mobile app" Claude Design handoff:
27 wireframe screens across 6 design turns, rebuilt as a real web app on top of the
Modernist design system, plus three screens wired to a free GitHub Models AI pipeline.

## Structure

- `src/components/frames/` — real React ports of the design tool's `IOSDevice` /
  `AndroidDevice` preview frames.
- `src/data/screens.json` — the 27 static screens, extracted from the original
  `.dc.html` export by `scripts/extract-screens.py` (Safebox → Akshayvridhi rebranded).
- `src/screens/TapFlow.jsx` — screen 4a, the one screen with real tap-through state
  (action → why → options → decided).
- `src/screens/FitScore.jsx`, `AdvisorCoPilot.jsx`, `Ask.jsx` — the three AI-driven
  screens (see below).
- `src/components/Logo.jsx` — the Akshay Vridhi lotus mark.

## Running locally

```sh
npm install
npm run dev
```

## AI features

Screens 3c (fit-score explanations), 4c (advisor co-pilot briefing), and `/ask` (FAQ)
read from `src/data/ai/*.json`, generated by `../ai/run-all.mjs` against
`../ai/profile.json` using [GitHub Models](https://docs.github.com/en/github-models) —
a free, OpenAI-compatible inference API scoped to a repo's own `GITHUB_TOKEN` (no
external API key). See `.github/workflows/ai-pipeline.yml`.

Until that workflow has run at least once, these screens render their original static
wireframe copy — `src/data/aiContent.js` loads AI JSON optionally, so a fresh checkout
never breaks.

To generate content locally: `GITHUB_TOKEN=<a PAT with models:read> node ../ai/run-all.mjs`.

## Deploying

`.github/workflows/deploy.yml` builds this app and publishes it to GitHub Pages on
every push to `main` (and after the AI pipeline commits new content).
